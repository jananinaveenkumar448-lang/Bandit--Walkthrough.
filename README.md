# OverTheWire Bandit: Level 0 → 15 Walkthrough

A beginner-friendly walkthrough documenting my learning journey through the OverTheWire Bandit wargame.

## Objective

The goal of this project is to practice Linux command-line skills and basic cybersecurity concepts by completing Bandit Levels 0 to 15.

## Topics Practiced

* SSH and remote access
* Linux file and directory navigation
* Hidden files
* Special characters in filenames
* File permissions
* Searching for files
* `grep`
* `find`
* `sort` and `uniq`
* `strings`
* Base64 decoding
* ROT13
* Hexadecimal conversion
* `gzip`
* `bzip2`
* `tar`
* SSH private keys
* `scp`
* Netcat

## Walkthrough

The walkthrough contains:

* Login credentials
* Objective of each level
* Step-by-step procedure
* Commands used
* Simple explanations of the commands
* Screenshots of the practical work

## Tools Used

* Linux Terminal
* SSH
* SCP
* Netcat
* OverTheWire Bandit


## Learning Outcome

This walkthrough helped me gain hands-on experience with Linux commands, file handling, compression formats, remote access, and basic cybersecurity problem-solving.
